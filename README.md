## 🛠️ Compétences & Outillage SOC
* **Investigation d'incidents :** Phishing, analyse d'en-têtes bruts (*raw headers*), extraction d'IOCs.
* **Méthodologies & Procédures :** Protocole S.I.E.R.A, triage d'alertes, réponse à incident ransomware.
* **Sécurité E-mail :** Diagnostic SPF, DKIM, DMARC, détection de Typosquatting / Domain Spoofing.
* **Systèmes & Réseaux :** Analyse de logs (Windows/Linux), lignes de commande CLI, bases SIEM (Wazuh, Splunk).
